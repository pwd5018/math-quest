## Limits of this evidence

The GitHub Actions workflow is supplied but has not run on GitHub. Browser interactions above were performed during this local build; they are not a committed browser automation suite. Reduced-motion CSS, focus trapping, Escape dismissal, visible keyboard focus and labels are implemented; there has been no independent screen-reader/accessibility audit or physical tablet/phone testing.

The actual Firebase authentication UI, trusted device provisioning, scalable storage migration and live persistence adapter are intentionally unfinished future integration work. Firebase mode stays locked. Rules tests prove the tested database access boundary, not authenticated callable correctness, production App Check behavior, concurrency/replay protection, billing acceptance or end-to-end deployment. Those gates are detailed in [FIREBASE.md](FIREBASE.md).
